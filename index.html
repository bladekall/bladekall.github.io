Automacao Canais

▶ This application uses YouTube API Services

Automacao Canais is a private, single-user tool that uploads and schedules videos to its owner's own YouTube channels (Dinastia Fria and Cold Dynast) using the YouTube Data API. Every video is produced and manually reviewed by the owner before upload.

The tool is not offered to the public and only accesses the owner's channels, after explicit authorization through Google OAuth.
